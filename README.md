# league-sandbox

A throwaway shakedown repo for [waldo.Jarvis](https://github.com/waldo1001/waldo.Jarvis)'s GitHub League: it copies the conventions of `waldo1001/waldo.BCTelemetryBuddy` (spec-driven development, `/tdd-workflow`, `/spec-authoring`, plans with a blast-radius section, a CI workflow named `CI`) over a tiny plain-Node + Jest codebase, so the League's whole build ladder can be tested here before it ever touches the real project. Nothing in here is meant to last.
